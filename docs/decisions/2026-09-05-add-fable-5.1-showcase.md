# Add Fable 5.1 Showcase

- Status: accepted
- Date: 2026-09-05
- Owners: Design Skill Arena maintainers
- Scope: Fable model identity, routes, screenshots, and vote target namespace
- Supersedes: none
- Superseded by: none

## Context

The worktree contains a new 18-page collection for `Fable 5.1`. A public model release is complete only when the homepage registry, standalone routes, screenshots, cache versions, capture tooling, metadata, and vote validation all use the same identity.

## Decision

Add `Fable 5.1` as an additive model release with provider `Anthropic` and canonical slug `fable-5.1`. Register all 18 pages in the homepage gallery, expose statically generated standalone routes with canonical metadata, serve versioned WebP covers, use the guarded generic capture command, and allow the `fable-5.1-*` vote target namespace.

## Alternatives considered

- Register only the homepage cards — rejected because direct routes, metadata, screenshots, and voting would not share a closed release contract.
- Make the one-off Fable capture script the maintained entry point — not selected because the generic `capture:model fable-5.1` path already owns build reuse, locking, and resource checks for every model.

## Consequences

- Positive: the gallery, all 18 pages, assets, metadata, capture tooling, and votes use one stable Fable identity.
- Negative: adding another complete model increases static route and screenshot storage counts by 18.
- Operational: production publication still requires uploading `model-screenshots/fable-5.1/*` to the configured screenshot origin and deploying the generated site and vote function. Rollback removes the Fable registry entry, route directory, assets, hashes, capture registration, and vote slug together.

## Verification

- The registry contains 18 Fable entries in the intended display order.
- All 18 Fable routes are statically generated; an unknown route is rejected.
- Every Fable cover resolves to an existing WebP whose query version matches its content hash.
- Every generated page visibly contains the full `Fable 5.1` name.
- Vote GET and POST handling accepts `fable-5.1-*` targets.
- The local homepage can filter to Fable and display exactly its 18 cards.

## Revisit when

- The public model name or provider attribution is corrected by the product owner.
- The screenshot origin or vote namespace contract changes.
